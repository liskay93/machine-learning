# 1단계 부록 — Ridge / Lasso / LightGBM 중 무엇을 쓸 것인가

## 0. 용어 정정 — Lasso 가 제곱이 아니다

| | 벌금 모양 | 이름 | 계수를 0 으로 만드나 |
|---|---|---|---|
| **Ridge** | λ·Σβ² (**제곱**) | L2 | 아니오 — 0 에 가까워질 뿐 |
| **Lasso** | λ·Σ\|β\| (**절댓값**) | L1 | 예 — 정확히 0 |
| Elastic Net | 둘을 섞음 | L1+L2 | 예 (L1 비중만큼) |

**왜 절댓값만 0 을 만드나.** 벌금을 줄일 때 받는 이득의 크기가 다르다.
계수를 0.01 에서 0 으로 옮기면 —
  · 제곱 벌금은 0.0001 만큼 줄어든다. 거의 아무 이득이 없으니 0 근처에서 멈춘다.
  · 절댓값 벌금은 0.01 만큼 줄어든다. 크기와 무관하게 **줄이는 대가가 끝까지 일정**하므로 0 까지 밀어붙인다.
세금으로 비유하면 제곱은 누진세(작은 것엔 거의 안 물림 → 살아남는다), 절댓값은 정액세(작은 것이 유지비를 못 견딘다).

**실측 (buyout, 표준화 계수, 전체 표본)**

| 설계 | OLS 0 개수 | Ridge 0 개수 | Lasso 0 개수 |
|---|---|---|---|
| 변수 4개 | 0 / 4 | 0 / 4 | **2 / 4** (term, credit 제거) |
| 변수 20개 | 0 / 20 | 0 / 20 | **14 / 20** (lag 1~4 대부분 제거) |

Ridge 는 credit 계수를 −0.0158 → −0.0023 으로 줄이기만 했고, Lasso 는 정확히 0 으로 없앴다.

## 1. 측정 — LightGBM 은 이 문제에 맞지 않는다

OOS 2012Q1~, 56분기, 동분기 팩터 4개, r2_oos 는 확장창 평균 대비.
LightGBM 도 다른 모델과 똑같이 훈련창 안쪽 시간순 CV 로 하이퍼파라미터 4조합을 탐색했다.

| 시리즈 | OLS | **Ridge** | LightGBM |
|---|---|---|---|
| buyout | 0.527 | **0.625** | 0.373 |
| hfri_fof_cons | 0.716 | **0.794** | 0.643 |
| epra_nareit | 0.566 | **0.622** | 0.481 |

**LightGBM 이 3개 전부에서 단순 OLS 에게도 진다.** 이유는 표본이다. 분기 자료 56개에 변수 4개면
트리가 쪼갤 거리가 없다. 트리는 자료를 구간으로 나눠 구간별 평균을 내는 모델인데, 56개를 나누면
구간마다 몇 개씩밖에 안 남는다.

**외삽 한계.** 트리는 훈련에서 본 범위 밖을 예측하지 못한다 (구간별 평균이라 그렇다).

| 시리즈 | 실제 수익률 범위 | Ridge 예측 범위 | LightGBM 예측 범위 |
|---|---|---|---|
| epra_nareit | −28.3 ~ 16.3% | −22.7 ~ 22.3% | **−14.2 ~ 19.7%** |
| buyout | −10.1 ~ 13.1% | −6.4 ~ 9.8% | −7.4 ~ 9.1% |

상장 부동산이 −28.3% 까지 빠진 분기가 있는데 LightGBM 의 최대 하락 예측은 −14.2% 다.
위기 국면에서 구조적으로 덜 맞힌다. 자산배분에서 하방을 과소평가하는 모델은 위험하다.

**단, 정직하게 덧붙인다.** 2020Q1 코로나 한 분기만 보면 buyout 실제 −10.05% 에 대해
OLS −5.86 / Ridge −6.43 / **LightGBM −7.06** 으로 LightGBM 이 가장 가까웠다.
외삽 약점은 표본 전체의 예측 범위에서 드러나지 팩터가 크게 움직인 개별 분기마다 드러나는 것은 아니다.

## 2. 권고

| 모델 | 이 프로젝트에서 | 이유 |
|---|---|---|
| **Ridge** | **본 모델로 쓴다** | n=56, p=4~20 에 맞다. 8/8 로 OLS 를 이겼다. 팩터끼리 상관이 있어 축소가 듣는다 |
| **Lasso** | 진단으로 쓴다 | "어느 변수가 쓸모없나" 를 직접 보여준다. 최종 예측은 Ridge 로 해도 좋다 |
| Elastic Net | 선택 | 상관된 팩터를 Lasso 가 임의로 하나만 살리는 문제를 완화 |
| **LightGBM** | **쓰지 않는다 (이 단계에서는)** | 표본 부족 + 외삽 불가. 2단계 펀드 단위 캐시플로(수천 행)에서 쓴다 |

LightGBM 이 값어치를 내려면 두 조건 중 하나가 필요하다 — 표본이 수백~수천이거나, 관계가 비선형이거나.
2단계(Preqin 캐시플로)는 둘 다 만족한다: 펀드×분기 수천 행, J-curve·펀드 나이·빈티지 상호작용이 비선형.

## 3. 문헌

⚠ **출처 주의.** 이 세션에서는 학술 사이트(academic.oup.com, arxiv.org, uncipc.org)가 네트워크 프록시에서
차단돼 PDF 본문을 열지 못했다. 아래는 **웹 검색 결과 요약으로 확인한 제목·저널·연도·핵심 주장**이며,
본문 대조는 하지 않았다. 인용 전에 원문을 직접 확인할 것.

**이 프로젝트와 같은 문제를 푼 논문**
- Brown, Ghysels, Gredil (2023), "Nowcasting Net Asset Values: The Case of Private Equity",
  *Review of Financial Studies* 36(3): 945–986. 혼합빈도(mixed-frequency)·희소자료 기법으로 개별 PE 펀드의
  **주간** 언스무딩 NAV 를 추정. 보고 NAV 를 외삽하는 단순 방법보다 낫다. 바이아웃 평균 시장베타 ≈1.0,
  총위험 연 33% (VC 는 1.4 / 40%). **트리·부스팅이 아니라 상태공간·MIDAS 계열이다** — 이 저장소
  factor-nowcasting 의 모델 B 와 같은 계보. 저자 코드: github.com/orgredil/Nowcasting-PE-NAVs

**베타 감쇠(README 경고)와 직결**
- Couts, Gonçalves, Rossi (2024), "Unsmoothing Returns of Illiquid Funds",
  *Review of Financial Studies* 37(7): 2110–2155. 비유동 펀드의 허위 자기상관은 펀드마다 따로가 아니라
  **같은 자산에 투자하는 펀드끼리 공통 성분**이 있고, 전통적 언스무딩(Geltner AR(p))은 이를 못 걷어내
  **체계적 위험을 과소평가**한다. 일반화된 언스무딩을 제안. 결론적으로 비유동 펀드 알파는 알려진 것보다 낮다.
  → 우리 README 의 "보고 베타 = (1−θ)×경제 베타" 보정도 이 논문 기준으로는 **불충분**할 수 있다.

**ML 이 언제 이기는가**
- Goulet Coulombe, Leroux, Stevanovic, Surprenant (2022), "How is machine learning useful for
  macroeconomic forecasting?", *Journal of Applied Econometrics*. 네 가지 결론: (i) **비선형성이 진짜
  게임 체인저**이고 정규화가 아니다, (ii) 표준 팩터모형이 여전히 최선의 정규화, (iii) K-fold CV, (iv) L2 손실.
  이득은 **거시 불확실성·금융 스트레스·주택버블 붕괴 국면에 집중**된다.
  → 우리 결과와 일치한다. 변수 4개 선형 문제에서 LightGBM 이 진 것은 비선형성이 없기 때문이다.
  (주의: 이 논문의 K-fold 권고는 거시 패널 맥락이다. De Prado 계열 금융 ML 문헌과 상충하며,
   이 저장소는 시계열 CV 만 쓴다는 규칙을 유지한다.)

**"변수를 줄여라" 의 반례**
- Kelly, Malamud, Zhou (2024), "The Virtue of Complexity in Return Prediction",
  *Journal of Finance* 79(1): 459–503. **모수 수가 관측 수를 넘는** 복잡한 모형이 충분한 축소와 함께
  쓰이면 단순 모형보다 낫다 ("benign overfitting"). 단순 모형은 예측가능성을 **과소평가**한다.
  → 우리의 "시차 팩터 20개는 해롭다" 와 겉보기에 충돌한다. 차이는 축소의 세기와 특징량 생성 방식
  (Random Fourier Features)이다. 시도할 값어치는 있으나 표본 56개에서 검증이 불가능하다.

**축소 vs 변수선택**
- Hastie, Tibshirani, Tibshirani (2020), "Best Subset, Forward Stepwise or Lasso?",
  *Statistical Science* 35(4): 579–592. 신호대잡음비(SNR)가 **낮으면 Lasso**, 높으면 best subset 이 낫다.
  relaxed lasso 가 전체적으로 가장 안정적.
  → 분기 수익률은 대표적인 저SNR 자료다. **선택보다 축소** 를 택할 근거가 된다.
